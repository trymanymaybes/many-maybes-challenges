# Challenge 11 - Was that always there?

Look once, note what stands out, then look again with a new cue. Afterwards, turn the same three arches into three different possibilities while keeping every original mark visible.

Try the observation exercise first: https://trymanymaybes.github.io/challenge-11.html

Run starter.py with desktop Python Turtle, or paste it into the browser playground. The three example scripts preserve the same three arches. They are illustrative possibilities, not prescribed answers. No third-party Python packages are needed for these standalone scripts.
